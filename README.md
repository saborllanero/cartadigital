# El Sabor del Llanero — Carta digital

Sitio estático listo para GitHub Pages. Sin instalación, compilación ni dependencias.

## Publicar
1. Descomprime el ZIP.
2. Sube el contenido de esta carpeta a la raíz de tu repositorio (index.html debe quedar en la raíz).
3. En GitHub, entra a Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Carpetas
- index.html: estructura y formularios.
- css/estilos.css: diseño negro, responsive y animaciones.
- js/app.js: categorías, búsqueda, productos, carrito y solicitud por WhatsApp.
- datos/menu.js: datos usados por la página; editar aquí los productos y precios.
- datos/menu.json: copia legible de los datos. Si modificas precios, actualiza ambas copias.
- img/: logo y 65 fotografías originales separadas de las capturas recibidas.

Se puede abrir index.html directamente para revisar el sitio. Todas las rutas son relativas y sirven en repositorios de GitHub Pages.
